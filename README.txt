REGINA FILMS — HTML + CSS

Откройте index.html в браузере. Сборка, JavaScript и сторонние зависимости не нужны.
Для размещения загрузите index.html, styles.css и папку assets на любой статический хостинг.

ССЫЛКИ НА ПРОСМОТР
Поскольку реальные адреса не были предоставлены, сейчас карточки открывают временные окна.
В index.html замените ВСЕ вхождения:
  href="#watch-1" — на ссылку первой серии;
  href="#watch-2" — на ссылку второй серии;
  href="#watch-3" — на ссылку третьей серии / закрытого клуба.
После замены можно удалить три блока div.modal в конце HTML.
Ссылка Instagram уже подключена.

ДОБАВЛЕНИЕ СЕРИЙ
Скопируйте article.episode внутри episode-grid, замените картинку, номер серии и все ссылки.
Изображения находятся в assets. Страница адаптируется под телефон, планшет и компьютер.
